# Kotak Neo SDK. NOT on PyPI -- `pip install neo-api-client` fails with
# "No matching distribution found". It only ships from GitHub.
#
# NOTE the repo name: the old Kotak-Neo/kotak-neo-api now 404s (a clone of it
# prompts for GitHub credentials, because GitHub returns 404 rather than 403
# for repos it will not serve anonymously). Kotak replaced it with
# Kotak-neo-api-v2.
#
# v2 is what this code actually needs. It calls client.totp_login() and
# client.totp_validate(), which do NOT exist in the old v1 line -- v1 exposes
# login()/session_2fa() instead, so v1 would import fine and then fail at
# login. Verified against v2.0.2: the NeoAPI constructor signature matches
# common_functions.py:102, and all six methods this codebase calls exist
# (totp_login, totp_validate, place_order, order_report, positions,
# cancel_order), including all 14 place_order kwargs used in orders.py:52.
#
# Pinned to a release tag rather than a branch so a future reinstall cannot
# silently pull a breaking change into the SDK that places your orders.
# To move upstream, change the tag deliberately and re-run deploy/smoketest.py
# -- it checks the SDK method surface, not just that the import works.
neo_api_client @ git+https://github.com/Kotak-Neo/Kotak-neo-api-v2.git@v2.0.2
